# Tools

OpenZL provides several web-based tools to help you understand and debug your compressors.

## [Trace Visualizer →](/tools/trace/)

Upload a CBOR trace file generated by OpenZL and get an interactive graph visualization showing:

- How data flows through the compression graph
- Which codecs are applied at each stage
- Performance metrics for each encoding step
- Detailed inspection of intermediate representations

## [Compression Playground →](/tools/playground/)

Benchmark OpenZL against standard compressors on your own data, visualize size vs speed trade-offs, and train custom compressors — all in the browser.
